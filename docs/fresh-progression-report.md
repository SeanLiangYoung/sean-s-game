# 从零开荒与遗物替代实测（2026-10-25）

本轮取消预置遗物与训练预算。所有正式样本从游戏新档开始：真实六名初始角色、八件初始装备、40银币、3份补给、0经验，各人只有一级基础技能；无图鉴、成就或跨档加成。通过真实路线、战斗胜利、战利品、商店、训练、补给、撤离与付费招募接口推进，失败后不读档重试。

## 本轮改动

- 新生成路线的胜利经验池基础值从120提高到200，原有层级、精英与首领增量保留。五人生还且没有击杀经验的支援角色，两场普通胜利从合计48经验变为80，足够支付基础技能二级45与首个分支30。旧固定遭遇的经验公式保持原规则。
- 每次远征首次**购买**遗物减15银币；常见70银币遗物首次55，后续原价。免费战利品与购买技能书不消耗优惠。判断使用已有购买历史，存读档保留；商店按钮、绑定页、实际扣款共用报价。
- 遗物奖励保留主主题延续槽、异主题槽与全目录随机槽；异主题槽优先补齐已持有一件的副主题，再考虑已有共鸣。仍排除已持有重复物品，未指定固定遗物名称。

三项调整一起复测，结果反映组合方案，不能把所有增益分别归因某一项。冻结战斗规则、敌人、装备与单件遗物数值没有随此实验变动。商店显示已同步实际优惠。

## 固定实验方法

三位团长（沈烬、闻笙、陆衡；按已可选角色分别重开零成长档，不导入解锁档的属性与资源），四种出战优先级：均衡（团长、刀客、游侠、医师、机关师）、守卫（以守卫替换机关师）、支援（以守卫替换刀客）、突击（以守卫替换医师）。这些是从真实初始六人中选出的五人；永久伤亡后仅用现存队员或真实付费招募补位。

每队比较两种固定策略：按当前可见收益兼顾恢复的自适应策略，以及更重视遗物的策略。策略合法分配现有装备，用实际赚到的经验按前置训练，购买有用书籍与遗物，使用真实野外和战斗药品，并按存活队员收益选择撤离保留物。没有未来路线、未来掉落或胜负预知。训练与操作策略有能力上限；这里不是人类玩家胜率，也不是旧版自动战斗基准。

首区域实验覆盖新档能直接进入的五个区域；废墟必须先解锁，不伪装为新档可选。正式前后各240次，40个独立初始掉落种子块，跨团长与策略配对。另留出20个不同初始种子块的120次验证。六区连续实验按边境、林地、荒原、冻原、沼地、废墟推进，前后各72次，共12个初始种子块，其中8个与首区域实验重合；撤离后的资源、训练、保留遗物和永久死亡持续继承。

同初始种子、同决策规则用于配对；购买、选择与存活状态变化会使后续随机数消耗和路线自然分化，并非保证六区全程逐节点相同掉落。跨角色及策略重复不能当成全新独立种子。

## 首区域与完整六区结果

首区域通过率从232/240（96.7%）提高到238/240（99.2%）。首领前两件共鸣从228/240提高到231/240；四件共鸣从7/240到8/240；两个两件共鸣的混搭从6/240（2.5%）到38/240（15.8%）。统计使用进入首领战前快照，排除首领战后奖励。八种主题均有出现。

首区域配对中8次由败转胜、2次由胜转败，并非每个种子都改善。调整后沈烬80/80、闻笙79/80、陆衡79/80。按出战优先级，均衡、守卫、支援均60/60，突击58/60。独立留出验证119/120（99.2%）：均衡30/30、守卫29/30、支援30/30、突击30/30。

完整六区通过率从25/72（34.7%）提高到31/72（43.1%）；配对18次由败转胜、12次由胜转败，后续路线分化不能简单解释为每场战斗强度降低。均衡9/18→10/18，守卫6/18→7/18，支援5/18→5/18，突击5/18→9/18。调整后沈烬10/24、闻笙11/24、陆衡10/24。四种队伍优先级均有通关案例；12个“团长×队伍”分组中11个有通关，陆衡支援组本次0/6，支援长线仍偏弱，不能据首区域接近全胜宣称六区已充分平衡。

## 实际拿到过的热门遗物拒选

先从调整后首区域成功记录中，按首领前**实际获得次数**排列候选，冻结名单与干预病例，再运行拒选。候选为dusk_2、hunt_3、hunt_4、arcane_3、dusk_4；这是频率排序，不代表已证明这些遗物过强。每个病例原本确实取得被禁集合至少一件，既不是挑完全没遇到的种子，也不是假定每个病例都遇到全部候选。

拒选只改变真实奖励和商店中的选择，不暗换掉落；可选其他战利品或资源，后续路径允许自然分化。单禁结果：dusk_2为23/24、hunt_3为22/24、hunt_4为24/24、arcane_3为23/24、dusk_4为24/24；前三件集合同时拒选为69/72。合计185/192，原配对病例186/192成功（6次由败转胜、7次由胜转败）。候选频率使用成功记录排名，干预病例按真实取得筛选，包含6条原本失败的重复病例，未事后删除。病例跨拒选组存在重复，共30个初始种子块，不能当成192次独立抽样。

干预后的实际轨迹中，192条单区病例有165条在战利品中再次看到被拒集合、36条在商店看到；21条六区病例分别为17条与9条，两类可重叠。干预改变后续选择后未再遇到不等于原病例从未获得，筛选依据始终为干预前的真实取得记录。

再从六区原本成功且首领前实际持有前三集合遗物的记录中，按团长与队伍分层，每组最多取两条，冻结21条病例，同时拒选前三集合。最终11/21完整六区通关：沈烬4/8、闻笙4/7、陆衡3/6；原配对21/21成功。说明三位团长都存在替代通关路径，但拒选使其中10次失去原有通关，长线对选择和续航仍然敏感，不能宣称热门遗物已完全无影响。这里仅测试候选集合，不证明所有110件都不存在必要性，也不应据此继续削弱出现频率高的物品。

## 审计、复跑与局限

原始数据保留每次奖励选项、商店货架及当时可负担项、购买报价和净扣款、训练前后经验、野外与战斗补给、出战与生还者、招募、战前构筑及失败位置。望镜等取得时返银的物品分别记录价格与取得奖励，避免把返银误判为免费购买。所有模拟仅替换存盘和跨档成就同步，战斗和成长调用游戏真实逻辑。

`tools/summarize_fresh_progression.py`审计所有初始状态、无拒选物品取得、训练扣费、购物收支、源文件一致性和配对病例，生成`artifacts/fresh-progression-summary.json`。正式冻结源代码前后只有`campaign.gd`、`relics.gd`不同，三个策略脚本完全相同，运行期间源文件无变动。工作区有其他并行功能，因此应使用冻结包复跑，不把最新工作区当作历史实验源码。

原始首区域文件为`artifacts/fresh-runs-{baseline,final,holdout,refusal}-{shen,wen,lu}.json`，六区为`fresh-runs-campaign-{baseline,final}-{shen,wen,lu}.json`及`fresh-runs-campaign-refusal.json`；两份拒选病例文件与排名计划一并保存。

冻结包为`artifacts/fresh-progression-baseline-sources.zip`及`artifacts/fresh-progression-final-sources.zip`，含独立源码清单与校验值、运行脚本、拒选病例。它们是模拟源代码包，不是包含所有界面资源的发行包。

解压到独立目录后，用Godot 4.7.2执行：

```sh
Godot --headless --path <解压目录> --script res://tools/simulate_fresh_runs.gd -- --label=replay --captain=shen
Godot --headless --path <解压目录> --script res://tools/simulate_fresh_runs.gd -- --label=replay-campaign --mode=campaign --count=3 --captain=shen
Godot --headless --path <解压目录> --script res://tools/simulate_fresh_runs.gd -- --label=replay-refusal --case-file=res://artifacts/fresh-refusal-cases.json --captain=shen
Godot --headless --path <解压目录> --script res://tools/simulate_fresh_runs.gd -- --label=replay-holdout --seed-start=2026103600 --count=1 --captain=shen
```

替换团长为wen、lu覆盖其他分组。固定策略和有限种子不能代表所有角色、所有操作水平与所有随机结果。没有强行把全流程胜率拉到100%；本轮优先解决短路线经验不足、副主题难补齐和首购门槛，同时明确保留六区续航差异供后续迭代。

最终验证：`python3 tests/verify.py`通过71套、89,729项检查，包含新增129项成长/优惠/副主题回归及161项零成长流程验证，场景加载和原生外观渲染通过。摘要审计全部正式病例通过；冻结最终源码包独立解压后8次开荒复跑均通过、无流程错误或运行中源码变化。
