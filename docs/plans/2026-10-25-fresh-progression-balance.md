# 从零开荒与遗物依赖实战 Implementation Plan

**Goal:** 不预配遗物/技能，不读取账户成就加成，测试真实成长中的成型率、远征/整轮通关率和热门遗物依赖，依证据调参。
**Architecture:** 标准新档六人名单，三团长与四种真实出战优先序；新角色必须付费招募。固定可见信息战术，真实装备、掉落、技能训练、购买、补给、死亡与撤离。战役/工具均冻结并记录hash，策略不读取未来节点与敌方隐藏随机状态。记录获得/错过/支付与成长时间线，复测同种子主动不选热门遗物，区分相关性和选择干预。
**Tech Stack:** Godot实际Campaign与Rules，内存存档适配仅屏蔽磁盘/跨档成就，JSON与Python汇总。

1. 测试新档起点、训练支付与合法性、无免费遗物、无个人双槽、无成就继承，先跑小样本验证模拟器。
2. 三团长×四出战优先序×真实可进入区域/种子/两种奖励策略跑基线，逐项统计阶段与失败节点。
3. 依实测定位成型瓶颈或异常依赖；先补失败测试再调整经验/掉落/价格/数值，保留四档总体难度和基础装备定位。
4. 同种子对照、留出种子与放弃热门遗物对照，补充六区连续开荒验证；运行完整回归，保存源码、原始证据与报告。
