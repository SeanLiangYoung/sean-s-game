# 角色组合与混搭遗物实战平衡 Implementation Plan

**Goal:** 测试三位团长、全角色天赋和不同队伍配比，校准纯流派与跨流派组合，使通关不依赖固定阵容或固定遗物。
**Architecture:** 冻结当前角色、敌技、首领与数值代码。统一低档装备、每人360经验合法训练、满足前置等级及团长相同跨职业技能预算；六区、独立资源状态配对。主矩阵12支队伍×纯流派/28种两两混搭/高风险组合；另留无治疗与双治疗队伍作验证。记录队伍、角色、绑定、初始状态、胜负、回合和减员，分队伍与构筑分析而非只看总胜率。
**Tech Stack:** Godot实际Rules、独立RefCounted战术策略、JSON原始结果与Python汇总。

1. 新增可复跑模拟与快照，先测当前基线；检查所有角色天赋是否获得实际触发机会。
2. 对发现的叠加漏洞/数值失衡先补失败测试，再修正少量边界或数值，不更改基础装备定位。
3. 同快照、同种子复测混搭与留出队伍，检查是否以削弱多样性换取表面平均。
4. 运行专项与完整回归，保存原始数据、源码压缩包、分组报告和限制说明。
