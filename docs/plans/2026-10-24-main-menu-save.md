# 主菜单与存档 Implementation Plan

**Goal:** 启动显示主菜单，玩家可开始、继续、调整设置，并在游戏中保存及返回菜单。

**Architecture:** 沿用 main.gd 的模态窗口和 campaign.gd 的原子 JSON 存档。主菜单不加载或改写存档；继续游戏先验证再加载。新游戏覆盖前确认。战斗沿用开战前检查点，设置独立存储。

**Tech Stack:** Godot 4 / GDScript / ConfigFile / headless 场景测试。

1. 在 tests/menu.gd 添加启动菜单、无档禁用、开始/覆盖确认、保存/继续、奖励恢复、损坏档案和设置持久化测试；运行观察失败。
2. 在 game/main.gd 接入主菜单、暂停菜单、确认操作、保存反馈和设置。游戏菜单阻挡世界移动与敌方行动；战斗中返回菜单须说明回退。
3. 在 game/campaign.gd 开战前保存检查点，增加保存时间并兼容旧档案。新游戏保存失败时保留原有游戏与存档。
4. 验证新测试与 tests/verify.py 全套；更新 README 操作和存档限制。

验收：首次启动停留菜单；有合法存档时继续可用；手动保存重新进入状态一致；战斗继续回到开战前；设置单独持久化；不在测试中覆盖玩家档案。
