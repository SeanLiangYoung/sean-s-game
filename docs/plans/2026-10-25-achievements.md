# 通关成就 Implementation Plan

**Goal:** 六区全部通关后按整体难度解锁永久成就，为全队提供少量属性。
**Architecture:** 四个独立难度成就，分别提供攻击+1、护甲+1、攻击+1、护甲+1，全部获得合计攻击+2、护甲+2。只解锁实际通关难度，不自动补发低难度。当前存档携带成就，独立本机档案保留跨新游戏与快照回退的成就。旧存档完整通关时补发对应难度。所有属性与装备预览统一经过战役属性计算。
**Tech Stack:** Godot / GDScript / 本地 JSON。

1. 新增 tests/achievements.gd：验证未通关无奖励、各难度全通成就、重复不叠加、跨新游戏与快照保留、旧存档补发、存档校验、战斗属性。先运行确认失败。
2. 新增 game/achievements.gd；接入 game/campaign.gd 存档、结算、属性与招募；修改装备/转职预览使用相同属性入口。
3. 新增 tests/achievements_ui.gd 验证入口、锁定、进度与奖励；实现主菜单/旅途菜单成就页和结算提示。
4. tests/verify.py 加入新套件，执行完整验证，更新 README，记录结果。

本工作区已有大量未提交功能，直接在当前工作区增量修改，保留既有工作，不提交或重置其他更改。
