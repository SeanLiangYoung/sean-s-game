# 商店、角色档案与遗物图鉴 UI 统一

承接 FB-010 与首批精简：复用深色/金色卡片、图标数值、独立详情层。价格、代价、不可逆绑定/替换、禁用原因保留在操作处。

1. 新增用例先验证：背景下沉且返回保留角色；商店查看不扣款，真实购买与售罄刷新；个人遗物仍需绑定确认；图鉴筛选/搜索/分页保持上下文，覆盖全部110件；主操作适配1280×800。
2. 扩展 compact_ui 通用卡片/页头与图标。商店按类型筛选卡片，招募同步卡片化。
3. 档案保留画像和属性摘要、装备/技能/转职快捷入口。技能树保留当前/下级收益与训练费用；冗长天赋、完整技能、书籍说明进入详情。职业用紧凑比较卡片；物品明确全队作用范围；所持遗物统一摘要卡。
4. 图鉴每页6件，固定主题筛选与搜索、分页入口；完整触发/共鸣在详情，关闭不重建原页面。
5. 定向回归、完整verify、原生截图并视觉检查。仅界面层，不改交易、角色成长、遗物或战斗数值规则。保留现有并行改动与正在运行的游戏。

用户后续明确要求：尽量改用语义图标按钮，补齐悬停及无障碍名称，价格/数量和风险原因保留。采用购物车、放大镜、书本、人物、衣甲、背包、钻石、箭头等通用形状；用明确当前栏目文字消除分类歧义。
