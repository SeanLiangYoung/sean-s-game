# 商店、角色档案与遗物图鉴统一 · 2026-10-25

承接[首批 UI 精简](2026-10-25-ui-optimization.md)与反馈 FB-010：常用操作直接可用，重要状态使用图标与必要数值，完整说明进入独立详情；费用、代价和不可逆后果保留在操作处。

## 图标语义与操作规范

按用户补充，尽可能使用图标按钮替代文字操作：放大镜搜索、叉圈清空、箭头返回/翻页、购物车购买、人物加号招募、链环绑定、书本加号学习、上箭头强化、衣甲装备、背包装物品、钻石遗物、环箭头旋转/重置。图鉴八个主题使用血滴、准星、盾、星芒、齿轮、叶、月、旗区分，并显示当前主题名。

- 图标按钮具有悬停说明、完整无障碍名称与描述，保留标准键盘焦点；按钮至少44高、48宽。
- 价格、书籍数量、强化经验保留数字；当前栏目、收益/代价、禁用原因和永久损失警示保留必要文字，不要求玩家猜费用或后果。
- 金色选中背景使用深色图标，暗色背景使用金色图标，禁用态另行降低亮度。
- 共享战斗指令、返回/关闭与装备预览旋转/缩放也同步图标化。角色卡片、商品及技能节点仍保留对象名称，便于识别选择对象。

## 页面变化

- **商店**：商品改为双列卡片，价格即购买入口，直接显示主要收益/代价、装备属性、售罄或银币不足。支持全部/装备/遗物/物品分类。查看详情不购买；个人遗物先进入佩戴者确认，取消不扣款，返回保留分类。首购折扣仍由原有交易规则报价。
- **招募与绑定**：统一人物卡片、真实模型头像、招募/绑定按钮。人物背景和完整天赋按需查看；已在队伍、队伍满员、银币不足与旧遗物永久替换均直接提示。
- **角色档案**：紧凑工具栏、独立角色列表和图标属性，装备/技能/职业快捷入口留在首层。背景、完整天赋、基础规则与共鸣进入详情。装备保留全身预览与槽位，属性改为图标摘要，完整数值单独查看。
- **技能与职业**：技能树保留当前/下级收益，训练费用、不可训练原因和操作按钮置于面板上方。完整技能与天赋另行查看；技能书通过明确入口进入卡片列表，学习后返回原角色技能页。职业卡片保留属性变化、免费转职按钮与阶段限制，专精及完整技能按需查看。
- **遗物持有页**：摘要卡片显示作用范围、来源、佩戴者、剩余次数、收益与代价；已持有个人遗物正确显示“已绑定”。完整触发和共鸣进入详情。
- **遗物图鉴**：固定主题筛选和搜索，每页6件，分页入口固定可见；保留并行开发的遗物发现规则：已解锁内容可访问，未见过的遗物不被搜索提前揭示。支持名称、主要收益与代价搜索，有明确空结果。详情不获取遗物、不重建原列表，关闭保留所在页、筛选与搜索。
