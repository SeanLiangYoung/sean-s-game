# 彩色村庄、片段故事与遗物构筑 · 审核版

## 目标与版本

基于 `75c983d`，在 `codex/village-story-relics` 实施。用户要求画面、故事、遗物策略互相支撑，并授权持续实施、内部迭代后再审核。本轮选择完整村庄与远征衔接作为可玩样板，不把六区所有战场重制纳入本轮，也不改已接受的难度与数值。

设计见 `docs/superpowers/specs/2026-10-25-village-story-relics-design.md`，实施计划见 `docs/superpowers/plans/2026-10-25-village-story-relics.md`。

## 已落地的体验

营地默认变成原生3D村庄；“选择远征”进入原有大陆地图，允许返回村庄。七间彩色风化房屋、冷色水面与荒野、远处悬石、暖窗光、晾晒与工作物件组成画面。门牌可交互，原生角色与装备外观继续生效。以 Териберка 的荒野与房屋对比作为气氛参考，未拷贝照片或外部美术素材。

玩家是失去故乡后借住的外来者。开场“一碗热汤”自愿阅读，随后通过拜访和归来见闻认识居民。六区各有到达、深入、首领胜利后片段；总计33个常规片段（开场1、房屋14、区域18），另有按住处记录的离世片段。村民与旅人各自只说局部经历，不直接揭示灰潮、遗民拓地、魔物迁徙的整条因果。灰潮没有人格或善恶。

阿禾的房屋一直保留。队员阵亡后，其房屋不消失、窗灯熄下、记录留下的住处，不会首次触发他活着时的交谈。每次远征后可选择一间尚未修缮的房屋帮忙，使用抽象的余力，不奖惩银币补给；新木板与漆色出现在房屋上。修缮、见闻随战役存档和原有检查点回退，不跨新游戏保留；旧档缺少故事字段时安全迁移。

遗物页新增整队构筑入口，区分全队底座与各角色实际共鸣，给八主题提供打法建议。奖励显示新激活2/4件的实际队员与效果；个人遗物绑定预览替换后失去/获得的共鸣。多个队员的个人遗物不会错误合并；重复ID、耗尽遗物不会虚增计数。遗物详情加入短小生活痕迹，不修改目录数值、战斗规则或抽奖随机序列。

## 内部迭代与审查

- 真实截图发现初版视角过高、房屋过小、悬石出框；调整相机、构图与门牌。
- 修复屋顶单面不可见、过密屋顶线、静态球形烟、直线水岸；改成完整屋顶、粒子烟和曲岸。
- 房屋阅读改成保留村庄背景的短对话窗；见闻列表和战利品线索保留可见标题，避免只出现难辨的详情图标。
- 回归检查找出旧原野从村庄切换后没有重建、营地缺少可换装的主角模型，均已修复。
- 修复阵亡后新解锁活人对话、JSON修缮计数整数往返、岳峙住处居民ID映射。
- 独立只读审查发现返回主菜单后地图选择状态残留，以及用主角共鸣代表全队奖励变化。加入失败回归测试后修复；复审无剩余具体阻断。

## 验证方法与边界

基线原checkout完整验证：90,024 checks，77 suites，含原生渲染，无失败。

新版本执行 `python3 -u tests/verify.py`，包括全部旧验证与村庄、故事、策略、流程和原生截图验证。最终汇总附于文末。

另运行 `tests/review_profile.gd` 的普通模式与 `-- --review-village` 模式，各1项通过；`zsh -n launch.command launch-review.command` 与 `git diff --check` 通过。

`tests/village_journey.gd` 通过真实页面回调连接拜访、出发、部署、结算、领奖、节点、撤离、修缮与读档。战斗以明确注入敌人零生命的状态触发胜利，**不是自然通关试玩或新的平衡研究**。策略测试另外与真实战斗的适用遗物/共鸣计算比较。没有声称新增真人留存证据、手机帧率或六区完整手动通关。

原生截图由 `tests/village_render.gd` 生成并检查，1280×800与1024×640横屏；审阅房屋门牌无重叠、主要按钮在屏内、奖励可比较、对话可读。PNG均为实际游戏画面，构筑/绑定/奖励截图使用受控持有物与奖励测试状态。

## 如何审核

在本分支目录双击 `launch-review.command`，新建普通难度旅途。它使用独立的 `ashbound-village-review.json` 与 `ashbound-village-review-settings.cfg`，不读取或覆盖正常旅途与设置。正常 `launch.command` 的存档路径不变。

建议先拜访阿禾的蓝门与邻居，再选择远征。奖励时看共鸣预览，归来后选择一间房屋修缮，打开旅途见闻重读线索。重点审核：村庄是否让人想回来；人物片段是否自然；遗物选择能否看懂区别。

本轮仍采用原创程序化环境与已有CC0人物，未达到定制角色动画、完整音乐音效和正式发行包的制作范围。新增房屋与遗物物件均为程序化几何/文字，无新增第三方资产。全部变更保留在审核分支，未合并main。

`python3 -u tests/verify.py`：**90,150 checks，82 suites，全通过**，含场景冒烟、原生人物/换装渲染与村庄渲染。原生村庄渲染独立32项通过。普通/独立审核存档入口另各1项通过。完整验证日志摘要保存于 `artifacts/village-verification.txt`。

完整验证后仅调整了村庄水面材质，降低重复亮点；重新执行原生村庄渲染32项并审阅新截图，全部通过。
