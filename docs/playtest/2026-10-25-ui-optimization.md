# 首批玩家体验优化 · 2026-10-25

依据本轮玩家反馈与用户明确要求：整体 UI 信息分层（FB-010）、移动预览（FB-005）、战后伤亡摘要（FB-012）。原始试玩资料另存于本机反馈清单。

## 已落实的玩家可见变化

- 新建旅途：开始按钮固定在页底；团长背景、完整天赋及难度规则通过详情查看，保留锁定原因与死亡风险。
- 战前部署：先显示选人卡片、已选人数、敌人数和永久风险，出战按钮固定；敌技去重，完整技能、强化与首领说明放入敌情详情。
- 战斗：六个常用指令采用两列按钮；生命、法力、行动点、普攻射程、防护及当前状态使用图标与必要数值。移除重复显示行动者的大面积横条，行动顺序靠前显示；技能、物品、休息选项在底部展开，不挤掉常用指令。共鸣、战场规则、日志放入详情；缩圈与超时死亡风险仍直接可见。没有选择指令时可点击单位查看完整状态。
- 奖励：五项紧凑卡片可同时比较，保留收益、代价和领取按钮；完整共鸣等内容单独查看。查看详情不领取奖励。
- 装备：点击槽位后自动滚动到可选装备，避免只见选中边框。
- 详情层：返回或 Esc 关闭后保留原页面与选择；查看期间战斗暂停。

## 移动预览

选择移动后，悬停可达格显示实际路径、费用及剩余行动点；点数耗尽时显示“将结束行动”。直接复用规则层寻路与费用计算，覆盖绕路、束缚、首格免费；途中敌方机关会预览截停点并提示伤害。取消、执行、切换行动或打开页面时清理预览。未更改寻路、费用或其他数值规则。

## 战后伤亡

结算先显示存活/阵亡人数、阵亡姓名和永久损失，无伤亡时明确“全员存活”；幸存者生命、法力、击杀可展开查看。摘要在奖励存档中保留，读档后仍可查看；普通战败后的摘要也可从暂停菜单“上一场战报”回看。没有摘要的旧存档照常兼容。Auto 的说明增加永久阵亡风险，保留随时手动接管。

## 验证

- `tests/compact_ui.gd`：59 项定向检查，覆盖首屏入口、详情返回、绕路/束缚/免费首格/机关的预览与实际扣点、取消清理、全员存活与阵亡、读档兼容、失败战报回看及解锁写入失败提示。
- `tests/compact_ui_render.gd`：原生运行截图，新建、部署、战斗、技能、休息、移动、详情、奖励及换装，共9个画面；实际以1280×800输出检查。
- 独立交付快照 `python3 tests/verify.py`（排除并行的未提交验证项）：72 个套件、89,794 项检查、零失败，场景启动及原生外观/装备渲染通过；完整日志见[验证输出](../../artifacts/ui-compact-verification.log)。
- 九个原生界面画面生成成功，未出现脚本错误；见[界面渲染输出](../../artifacts/ui-compact-render.log)。
- 首领表现测试改为固定随机种子，避免随机布局改变 AI 首次行动，使蓄力动画用例偶发失败；保留真实场景命令与动画链路检查。
