# Character assets and combat presentation

User request: replace primitive stone-like characters, add animation and feedback to attacks, skills and rest, research ready-made assets. Standing authorization permits autonomous implementation and review.

Approaches: proprietary custom production has the best style control but requires a separate art pipeline; CC0 complete fantasy packs provide immediately usable rigs and actions; natural-proportion base meshes require clothes and animation retargeting. Use a complete CC0 pack as an explicitly provisional visual upgrade while documenting the natural-proportion route. This is the implementer's choice, not an approved final character style.

All combat commands share a locked presentation timeline. Capture state before/after the deterministic rule command, retain the previous scene for anticipation, play the source action, show hit/recovery effects and floating actual deltas at impact, then rebuild and resolve victory/death. Enemy actions use the same mechanism. Invalid commands cause no timeline; duplicate input during playback does nothing. Movement follows its legal hex path. Rest distinguishes HP and MP. Preserve all existing rules and save formats.

Imported assets retain original license and source records. No purchases. Do not claim these packs match Tears of the Kingdom production quality. Verify imported animations, timeline locking, lethal result ordering and existing rule/UI suites; inspect native screenshots.
